# 七款风格演示复核（2026-11-10）

结论：目前没有发现七款风格的名称、模型索引或选定输出互相放错；**不能据此认定七款风格都已准确模拟胶片**。自然正片、浓彩风光、克制复古的现有演示不足以支持这种结论。宣传样片是调色配方展示，需要区别于默认滤镜效果。

## 查了什么

1. 从已安装 APK 读取七款胶片及所用相纸配置，与源码、应用 assets 和手机缓存比较。JSON 内容一致；部分源码采用 CRLF 换行，APK 用 LF，记录原始哈希差异，不把换行差异当作模型改变。
2. 核对七组新样片的输入、实际 Android 输出哈希、风格索引、胶片、相纸、正片扫描开关和所选配方。另复核旧版 80 个输出文件哈希、其中 56 个标准风格映射。
3. 逐张查看七组胶片参考、输入和调色结果；另排版同一输入的三种正片输出，以及全部七款的“输入 / 仅风格 / 手动配方”。照片等比缩放，没有额外调色。
4. 从最终视频的输入、输出、参考阶段抽帧，核对文件身份及屏幕关键参数。该检查验证放图正确，不评判胶片还原准确性。

## 实际看图后的判断

以下是针对这些具体图片的视觉判断，不是对某款胶片所有扫描的概括。

| 演示 | 当前可见问题 | 验收判断 |
| --- | --- | --- |
| 自然正片 | 成片海水偏灰蓝；参考是带雾光的青绿海岸。天空、天气和照明不同。 | 没达到参考的色彩观感，不能称接近已验证。 |
| 浓彩风光 | 草地比参考更黄、更亮，参考的绿地更暗、天空更深；手调蓝色明度和对比并不能证明默认 Velvia 模型正确。 | 有浓彩效果，色彩关系仍有明显差距。 |
| 克制复古 | 用人物对建筑，无法有效比较肤色；手调后的暗部和红衣更重，“克制”这个命名没有被这组样片充分支持。 | 验证力不足，需要同类题材参考及新的输入。 |
| 日常暖色 | 肤色变暖、蓝衣更清楚，但人物头发和背景暗部偏重，不能仅由此称为柔和。 | 可作调色示例，不能作 Portra 准确度证据。 |
| 电影日光 | 明暗和暖绿方向可见，修车区暗部较深；参考是另一种扫描/成像路径，并非 250D + 2383 同条件参照。 | 配方有效果，不能把印片观感直接等同于参考扫描。 |
| 夜色光晕 | 冷暖路面有层次，但原图已经具有蓝调和暖灯。参考中醒目的红色灯边光晕并未在现有输出中得到有效对照。 | 这张不能证明 800T 光晕模拟准确。 |
| 柔和黑白 | 咖啡馆成片黑位深、纹理强，配方还额外加了对比；不是柔灰展示。 | 灰阶转换可见，“柔和”不能由这张配方证明。 |

同一海岸和同一人像、强度统一为 65、无手动调色时，三种正片仍比较相似。风光的浓彩略明显，但没有充分形成三个直观的使用选择。这也说明，不能用七张不同场景加不同手调参数来证明七种默认风格区别很大。

## 参考本身的限制

参考胶片标签来自上传者描述；Vision3 250D 的证据是上传者所加胶片分类，未获得独立认证。夜景参考是明显欠曝后用相机和 Negative Labs Pro 重新扫描的结果；Velvia 参考明确用了 Cinestill Cs6 “Creative Slide” 冲洗套件。它们可以提供审美参考，不能当作唯一标准色。

因此没有为了追某一张扫描而直接改整个胶片模型，也没有把“好看”“有区别”和“准确还原”混为一个结论。下一轮风格优化需要在同一组手机输入上评价默认效果、肤色与高光，再决定调整或合并；现有材料不足以直接决定合并哪些。
