# 实验输入与衍生图署名

这组实验有四张 AI 生成输入（bay、garden、night、person）和两张真实手机照片（phone-street、phone-sunset），不能统称六张AI图。两张公开照片的作者处理历史未知，不声称未经处理的相机直出；它们也不是用户的私人相册照片。

| 场景 | 原作者与原作品 |
| --- | --- |
| phone-street | JacobLyu，[Changchun Treaty Port Zone Historical Culturual Block (Xinmin Hutong) 20260321](https://commons.wikimedia.org/wiki/File:Changchun_Treaty_Port_Zone_Historical_Culturual_Block_(Xinmin_Hutong)_20260321.jpg) |
| phone-sunset | JacobLyu，[Changchun Jiefang Avenue CBD from Pingyang Street](https://commons.wikimedia.org/wiki/File:Changchun_Jiefang_Avenue_CBD_from_Pingyang_Street.jpg) |

AI输入用于受控风格试验，不冒称手机实拍或真实胶片。官方飓风相机的参考宣传图和视频仅存本地研究目录，没有混入本实验输出或打包进应用。
