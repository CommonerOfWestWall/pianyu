# 实际导入照片复核与HEIF输出计划

**Goal:** 用用户已导入片屿的照片核验默认风格、胶片前曝光与少量微调，解释测光开关；实现不经JPEG中间文件的HEIF编辑后输出，保留手动控制。

**Architecture:** 保留现有ImageDecoder→sRGB像素→胶片核心链。HEIF只新增输出编码层，使用官方AndroidX HeifWriter稳定版1.1.0及手机编码器，不加入大型软件编解码库。导出格式扩展为JPEG/PNG/HEIF，旧lossless偏好与API兼容。编码失败明确报错并清理未完成文件，不偷偷改JPEG或缩小尺寸。8-bit SDR限制直接说明，不冒称HDR/10bit端到端。

**Tech Stack:** Kotlin/Compose、Android MediaCodec/AndroidX HeifWriter、现有引擎、JUnit/instrumentation/ADB；一位执行者拥有导出相关文件，主线程负责私人样片与验收，不能重叠编辑。

## 工作范围

- [x] 读取当前导入清单；只取用户已授权的片屿导入图，保留原文件字节与设置；私人照片与输出仅留本地研究目录，不能进公开源码、公开测试资源或宣传素材。
- [x] 根线程在真实安卓管线生成默认与小范围胶片EV/测光对照，视觉分析肤色、灰阶、色彩倾向、高光/暗部、颗粒与所选材料的关系。没有同场景/同光照胶片真值，不输出虚假的百分比准确率。
- [x] 导出执行者新增ExportFormat/HEIF编码、PhotoIO保存/分享、配方偏好迁移、单图/批量路径与UI；旧JPEG/PNG行为保持。检查编码器能力，失败可选JPEG/PNG，不伪装HEIF成功。
- [x] 真机测试HEIF文件容器/MIME/扩展名、完整尺寸、方向与色彩，重新解码对照输入调整后的像素；HEIF是有损输出，采用误差/视觉与通道测试，不要求逐像素相等。
- [x] 默认胶片曝光0解释清晰（自动测光后的额外补偿0）；默认不硬加正EV。只在实图证据支持时调整推荐工作流，高手可关闭测光、调EV/HSL等。
- [x] 主机测试、相关真机回归、Release构建/lint/签名/源码与APK匹配；最后给v12安装包及对应源码，不发布私人照片。

## 验收边界

HEIF文件必须解码成像素才能做常规调色，再编码为HEIF；这不是JPEG中转，也不是对压缩码流或传感器数据做无损编辑。当前渲染为8-bit sRGB SDR，原HEIF的HDR/gain map/10-bit数据不能据此保证保留。用户照片仅用于此次私人分析，不能推断真实人物身份，也不作为公开示例。

- 推荐起点保留几何，重置当前风格调色且可撤销；EV0说明已澄清。原保存编辑不自动改写。
- 21项真机回归和7项主机测试通过；HEIF容器/色块/方向/MediaStore、4096×3072私人输入往返通过。
- Release构建和lint通过：0 errors/32 warnings/1 hint；签名沿用既有测试证书。独立Release实际推荐起点、HSL、裁切旋转、PNG/HEIF保存和HEIF分享选择器通过；不选择分享接收人。APK/GPL源码已配对并校验，私人研究不纳入分发。
