# 片屿 0.2 编辑器改进 Implementation Plan

> 执行：按 executing-plans 推进。最多1个 luna_worker、fork_turns=none；工人只拥有明确的图像几何/调整文件，主线程负责产品、照片库、调度、界面、集成和验收，不交叉编辑。

Goal：批量导入/处理、可操作的自由裁切和校平、完整基本调色、可理解风格说明、名称相关图标，以及可测的加载体验改善。
Architecture：保留原生Compose+C++核心；新增轻量本地照片库和逐张批处理。先显示解码预览，再生成风格；有限LRU缓存、低分辨率交互、按需缩略图。输出几何与预览共用同一实现，配方复制默认排除逐图裁切/旋转。
Tech：现有AGP9.2.1、Kotlin/Compose、Android Photo Picker、ImageDecoder、Canvas/Bitmap、Vulkan，无新增生产依赖。

## 依据与约束

用户截图的四角按钮实际是缩放复位，文字缺失，改成只在缩放后出现的“恢复全图”。旧版只有单图和固定居中比例，不能满足基本编辑。以现有深石墨/黄铜视觉为基础，不复制VSCO的完整产品或声称功能等价。参考VSCO官方geometry和recipe说明及Android多选PhotoPicker文档；不把其Web/Studio Pro功能误称为Android已有功能。不删除现有照片、旧版安装包或原SpektraLab。

## 文件与里程碑

1. 数据契约：新 EditSettings.kt，保留旧字段兼容测试，加入颜色与归一化裁切/旋转字段；主线程负责。
2. 图像流水线：luna_worker负责 PhotoIO.kt、PhotoGeometry.kt、GeometryDeviceTest.kt。统一旋转90°、镜像、±20°校平无黑边、可移动矩形裁切；基本曝光/对比/饱和/高光/阴影/褪色/白平衡/锐化/暗角；像素端点和导出所有权不变。
3. 照片库与性能：主线程负责 LibraryStore.kt、EditorModel.kt、NativeCore.kt、MainActivity.kt。多选导入、持久URI、逐图设置、配方复制/套用、逐张批量导出、进度/取消/错误计数；960预览、先出原图、有限缓存和按需缩略图，记录各阶段耗时。
4. 界面：主线程负责 EditorScreen.kt、LibraryScreen.kt、CropEditor.kt、AdjustmentPanel.kt、Look.kt。照片库入口、长按多选、明确文字操作；全屏自由裁切拖角/移动、网格、比例、90度/翻转/校平；基本调色面板；每款说明真实参考材料与当前配方特征。
5. 品牌：新图标用胶片画框中的岛与日光解释“片屿”；保留源图与提示词。更新启动图标和关于说明。
6. 集成：升级0.2.0，构建lint与真机，验证几何坐标、颜色、同配方批处理逐图裁切保留、进度取消、保存尺寸、设置重开恢复、照片访问权限、反复切换缓存。截图来自实际运行与公开样本，不用设计图替代。
7. 交付：新APK/对应源码/验收记录/实际截图置outputs/独立胶片应用/v0.2；保留0.1。核对手机安装APK哈希和解压源码构建。未验收点必须明说，不以“基本跟VSCO一样”收尾。

## 可观察验收

- 一次选多张，照片库可见，单独编辑和重开后设置保留。
- 至少3张JPG/HEIF批量套色与导出，独立裁切不被复制覆盖；逐张运行内存受控，失败可继续，取消不覆盖原片。
- 自由框能移动/拖四角，比例准确；90°/微调/镜像导出与预览一致且无黑边，取消裁切不改变编辑。
- 所有新增调色非空按钮，强度0像素不变、默认设置不改色，输出尺寸有校验。
- 风格卡/说明显示实际胶片参考，不宣称扫描还原准确度；恢复全图文字可理解。
- 缓存再次切换避免重复核心计算；解码、首次风格、切换、导出分开计时，不承诺无证据倍数。
