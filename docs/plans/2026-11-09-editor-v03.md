# 片屿0.3图标与日常修图 Implementation Plan

目标：消除双重图标边框；在现有轻量编辑器里补齐分色调整和可保存的个人配方，不重写核心、不增加生产依赖。

依据：当前真机照片库截图见工作区audit-v03-start.png，画框在方形底图内形成第二个边界。现有代码只能保存最近复制的一份配方，无HSL，无法直接复用多套日常调色。Android官方adaptive icon要求108dp分层、核心位于66dp安全区，由系统决定外形；Play列表512px图标另外交付，不预画圆角与阴影。

约束：保留0.1/0.2交付、用户照片与编辑、C++核心和35个SPIR-V；无推送/发布/签名升级。现有源码工作区无可用提交基线，先打工作备份，不创建虚假历史。仅一个luna_worker、fork_turns=none，禁止再委派。

## 文件与分工

- 主线程：图标drawable XML及monochrome版本、adaptive XML与512px列表资产；EditorModel.kt、EditorScreen.kt、新RecipeStore.kt/RecipePanel.kt和RecipeDeviceTest.kt；README、品牌记录、版本及真机验收工具。
- luna_worker：HslSettings.kt、HslPanel.kt、EditSettings.kt、PhotoIO.kt、LibraryStore.kt、AdjustmentPanel.kt、HslDeviceTest.kt。不得修改主线程文件。

## 执行与可观察验收

- [x] 保存现有源码备份。图标用独立岛岸与日光的矢量，不再画外框；前景透明，背景满铺，重要轮廓落在安全圆内；给出圆形/圆角方形/水滴/主题单色和小尺寸预览，真机渲染核对。新资源不依赖AI位图编辑。
- [x] HSL八色：红橙黄绿青蓝紫洋红，色相/饱和/明度，平滑权重与低饱和保护；零设置精确不变，灰阶不染色；加入配方序列化/旧库兼容/撤销/逐图构图保留。UI为调色内的独立分色面板，避免24个滑块同时堆放。色条样本及公开照片实际输出检验，默认关闭不增加逐像素HSL开销。
- [x] 个人配方：将当前调色命名保存，列表应用/改名/删除（删除先有应用内确认）；AtomicFile持久化，失败不覆写原文件；应用时保留当前构图、更新可批量粘贴配方、支持撤销。旧library-v2.json不改结构，仅继续保留旧复制配方。独立存储recipes-v1.json。
- [x] 导出尺寸记住上次1080/2048选择；照片预览增加明确的“对比原图/返回效果”切换，原有长按和缩放仍可用。
- [x] 构建Debug/测试/压缩Release/lint；原10项及新增HSL/配方/图标共19项真机测试通过，Release交互流程通过；检查彩色图、分色操作、命名/改名/应用/删除、重启、保存/分享、原裁切和批处理回归。实际滑块校验记录请求值和触摸量化后的数值，不用“请求过”代替变化。
- [ ] 版本0.3.0独立输出；APK安装且回读核对，源码ZIP解压独立构建，交付实机截图、测试日志、图标比较和已知限制。未做曲线/透视/蒙版/后台服务，不声称与VSCO全功能一致。

研究来源：https://developer.android.com/develop/ui/compose/system/icon_design_adaptive?hl=en 与 https://developer.android.com/distribute/google-play/resources/icon-design-specifications 。图标“去框”是针对当前视觉问题的设计判断，并非官方禁止所有边框。
