# 第三版介绍片与样片核对

本片采用14段完整口播：从选片与风格，到白马调色过程、基础工具、配方批量和原尺寸导出。旁白可独立连贯理解；画面补充参考材料、默认强度和累计参数，不要求用户靠听旁白记数字。配音为AI合成，不公开音色名称或模型文件。

## 画面来源

七款默认风格均对应各自`02-new-default`的实际Android输出，不是后期软件另外调色的结果。风格名称、`lookIndex`、胶片/相纸、正片扫描开关、强度以及输入/输出SHA-256与样片manifest逐项核对。白马另展示原图与4个累计阶段，并列出实际参数；完整JSON保留在样片资料中。

本片的主要照片输入为AI生成的手机摄影风格场景，明确标注；不是普通用户实拍的背书。历史扫描资料属于独立研究，没有把异场景历史扫描当作本片处理结果。本片没有以1800多次实验代替1800张独立照片的说法。

照片输出和真实内置静物录屏来自versionCode7。versionCode8新增胶片曝光默认0，未改变这些默认材料和预设；旧素材不能证明新增控制的Android交互已经验收。批量能力按功能说明展示，未录到的操作不冒充真实批量处理录屏。

## 核对与边界

交付视频目录保留完整口播、SRT、时间轴、资产哈希、成片SHA-256、ffprobe、完整解码与音频峰值记录。照片前后对照使用相同裁切，通过擦拭转场展示；字幕与信息卡分开，音频保持完整。

最终成片为160.201秒、1920×1080 / 30fps，33条字幕，每条最多两行；45条资产哈希一致，完整解码通过，音频真峰值−1.1dBFS。成片SHA-256为`1959df2815944e46dec2ad1be34aa8ed753571cd980de48dd4495ef3e6e08b5d`，详细记录见视频目录的`验收-v3.json`。已逐项检查联系表和数值、裁切、配方及前后阶段代表帧；没有把这些检查声称为逐句人工听审。解码通过不能替代逐句听审，样片文件一致也不能证明历史胶片的审美已经准确复现。胶片材料模型与片屿额外预设分别说明，允许关闭额外预设自行创作。

这是制作第三版视频时的历史审阅记录，彼时新增胶片曝光尚未做真机验证。本次v12随后已完成针对性测试与最终Release真机流程，见[0.3.2发布说明](RELEASE-v0.3.2.md)；本页视频仍展示versionCode7，不作为新版验收或默认效果证据，也不在本次Release附件中。
