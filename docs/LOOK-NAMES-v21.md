# 片屿 v21 风格命名

在同一张输入上比较模板默认输出，用明暗、彩度、色相或风格用途命名。七款已有明确辨识度的名称保留。以下八款更新展示名。

| 原名 | v21 名称 | 命名依据 |
| --- | --- | --- |
| 克制复古 | 红蓝复古 | Kodachrome 底色的醒目红色、较深蓝色和克制的绿，适合街头与日常物件。 |
| 清透海岸 | 浅蓝淡彩 | 水面与天空更亮、蓝色更淡，晴日街景也可用。 |
| 林影暖褐 | 橄榄暖影 | 整体暖、黑位偏深，绿影收向橄榄，适合旧建筑与林荫。 |
| 青湾旅行 | 深青水色 | 相比浅蓝淡彩压深水面，并将蓝推向青色。 |
| 青金风景 | 暖金冷蓝 | 保留原片暖金主体与冷蓝背景的配色关系，适合已有暖光的风景。 |
| 暮色蓝调 | 蓝紫暮色 | 加强傍晚已有的冷蓝和轻紫，适合暮光天空、远山和水面。 |
| 深林清影 | 深绿林地 | 压低彩度，保留偏深的绿与岩水层次，适合林地与瀑布。 |
| 柔青海岸 | 灰青低彩 | 降低青水彩度、抬柔明暗，能用于雾感风景和阴天海岸。 |

岩岛青湾 06 使用同一输入和 75 强度时，浅蓝淡彩、深青水色、灰青低彩的水面 OKLab 中位明度 L×100 / 彩度 C×100 分别为 52.3 / 6.2、48.6 / 6.6、56.3 / 4.7。粉蓝湖城 05 的远山和湖水在蓝紫暮色下彩度分别为 7.2 和 6.5，浅蓝淡彩为 2.2 和 2.6。深林瀑布 19 的森林色相在橄榄暖影与深绿林地下约为 126° 和 147°。这些对照用于描述模板区别，实际结果也随输入颜色和光线变化。

历史研究中的名称按原版保留，按此表可查最新入口。配方和图库继续按原索引使用相同的材料、强度和完成层。新名新增 11 个 Noto Serif SC 600 字形，旧版 73 个字形轮廓与度量均保留。
