# v12：推荐起点与 HEIF 输出

## 新手打开就有效果，手动补偿仍为零

新照片默认：风格强度75、颗粒12.5、保护高光自动测光开启、胶片曝光补偿0。处理顺序是 **解码 → 自动测光 → 手动EV补偿 → 胶片响应/印片或扫描 → 片屿预设与用户调节 → 编码**。0只表示没有追加手动补偿，不表示跳过测光、颗粒或胶片模型。75是推荐配方位置，不是准确率。

风格说明内新增“重置此风格调色”。它把**当前所选风格**恢复到以上推荐调色，保留裁切、旋转、校平、镜像；可以撤销。旧照片和已保存配方不会静默改色，用户主动点击才更新。切换风格仍保留用户调节；想清除上个风格留下的色温、HSL、曝光等，再使用此按钮。

自动测光开关保留在调色面板：算法不知道创作意图，故意压暗的舞台、夜景、剪影不应被强迫提亮。新手可保持开启；手动创作可关闭，以原输入曝光作为起点。关闭不会关闭胶片响应。已有照片若来自旧版，可能保存了关闭状态。

该按钮只是恢复默认配方，不是自动分析题材或智能修图。新照片无需点击：原本就使用推荐默认值。当前按图分析的是自动测光，不自动选择色温、HSL、阴影等参数。

## 为什么不统一默认 +0.5EV

本轮通过授权测试输入做真实安卓渲染对照；私人照片、URI、设置清单及具体内容不进入公开仓库或分发包。

视觉比较发现：部分逆光主体加少量曝光更舒展；另一些风光加1EV会明显冲淡天空和岩壁。负片印片归一化会削弱手动EV对最终亮度的作用，暗部反差也不能全部靠EV解决。因此不把“胶片味”解释成固定加曝光，保留有依据的自动起点与独立手动工具。

没有同场景、同光照、可追溯充扫的胶片真值，不能给这批手机照片编造“胶片相似度百分数”。风格辨识与物理定标分开：可观察色彩倾向、调子与高光响应，不能据此声称已证明目标胶片准确率。夜景光晕与人物肤色也需要对应场景，不由普通日光风光替代验证。既有上游同输入对照与材料依据见 [上游实践](UPSTREAM-PRACTICE-2026-11.md)、[胶片性格复核](FILM-CHARACTER-AUDIT.md)。

## HEIF 原生读写的含义

导入本来就是Android ImageDecoder直接读HEIF到像素，没有先转JPEG。v12新增HEIF编码，完整路径为 **HEIF → sRGB像素 → 调色/构图 → HEIF**；普通调色必须解码再编码，无法对压缩码流直接做无损胶片处理。

在导出对话框选择“HEIF · 高效存储（设备支持时）”，单张保存、分享编辑后照片及批量保存使用同一格式偏好。可同时选择原尺寸。扩展名为`.heic`，MIME为`image/heic`，不是改扩展名的JPEG。仍可选JPEG或PNG；旧PNG偏好保留。设备不支持或编码失败会明确报错，不静默改为JPEG或缩小。

使用官方稳定版 [AndroidX HeifWriter 1.1.0](https://developer.android.com/jetpack/androidx/releases/heifwriter) 和设备HEVC/HEIC编码器，质量100；[质量100仍不等于无损](https://developer.android.com/reference/androidx/heifwriter/HeifWriter.Builder)。不打包大型软件HEVC编码器。

**当前输出为8-bit sRGB SDR**，不承诺保留输入HEIF的10-bit、广色域、HDR/gain map或EXIF。HEIF与JPEG都是重编码；需要不增加有损编码可选PNG，需要完全原文件可分享未编辑原片。HEIF也不保证在每张照片上都比已有原片小，接收软件是否支持由对方决定。

## 实际验证

Redmi K80 Pro / Android API36：HEIF容器、MIME、扩展名、红绿蓝通道、MediaStore保存/读取/删除自己的测试输出通过；带方向6的JPG和HEIF均以2304×3456渲染、HEIF保存并正确解码。额外一张已导入HEIF以4096×3072完整处理，输出HEIF后在安卓重新解码，与编码前像素比较的RGB平均绝对误差为1.60/0.88/1.87（0–255）。此误差衡量编码往返，不是胶片准确率，也不能推广为所有手机编码器的结果。

包内不含私人照片；调试研究Activity不进入Release APK。最终相同的Release APK已在Redmi K80 Pro重新安装并验证最终UI、HEIF原尺寸保存和分享。其他品牌的HEIF编码、超高像素和HDR仍需单独实测。

最后按用户反馈，把原“应用推荐起点”从风格主页收进风格说明，并改名“重置此风格调色”，避免误认为智能分析；补充HeifWriter许可。最终Release APK已再安装真机验证这些最终界面与HEIF流程。
