# 片屿 0.3.4 发布说明

片屿是一款本地运行的 Android 胶片调色工具。用 15 款风格作为起点，再调整胶片曝光、相纸或电影拷贝片与印放曝光。照片、视频和实况的处理都在设备上完成。

## 下载

- [Android 安装包](https://github.com/CommonerOfWestWall/pianyu/releases/download/v0.3.4/pianyu-0.3.4-arm64.apk)适用于 Android 10 及以上、arm64 设备，胶片引擎使用 Vulkan。
- [源码 ZIP](https://github.com/CommonerOfWestWall/pianyu/archive/refs/tags/v0.3.4.zip)对应 `v0.3.4` 标签。构建步骤见[源码归档说明](../SOURCE-DISTRIBUTION.md)。

GitHub 安装包为 0.3.4（versionCode 23），沿用之前公开测试版和 v22 的开发签名。已安装相同签名的片屿，可直接覆盖安装并保留应用内照片库和配方。

## 这一版的变化

- 15 款风格放在同一个列表。照片编辑页可直接打开「胶片曝光」或「相纸与印放」。已有照片与配方仍能读取。
- 在照片库选择「导入 RAW、视频或实况」。手机 DNG 经 LibRaw 解码，以高精度线性 RGB 进入胶片引擎，沿用照片编辑和导出流程。
- 普通视频支持抽帧预览、胶片风格、强度、胶片曝光和印放，保存为带声音的 SDR MP4。
- JPEG 实况照片的封面和内嵌视频可以同步调色。支持保存为实况照片或另存 MP4。

## 已验证的范围

在 Redmi K80 Pro 上使用合成样片，跑通了 320×240 DNG 的导入、曝光调整与原尺寸导出，同时核对了普通视频、JPEG 实况和实况另存 MP4 的颜色、时长与音轨。视频样片的四色输出与调色预览平均每通道差 2.5/255。原有照片调色界面也通过了回归测试。

视频使用固定曝光的颜色查找表。颗粒和光晕用于静态照片。不同品牌的 DNG 变体、相册实况播放，以及 HEIC/AVIF 实况容器仍需进一步验证。照片导出为 8 位 sRGB。
