# 0.3审查与验证记录

范围：图标、自定义HSL、命名配方、原图对比和导出尺寸记忆。不更换生产依赖、C++核心或材料库。

主线程审阅实际实现后修正：
- HSL初版饱和度计算缺少归一化，会错误增艳非目标颜色；已改为规范的归一化HSL。原先45°等间隔锚点与颜色名称不对应，改为红0/橙30/黄60/绿120/青180/蓝240/紫270/洋红300°，相邻锚点smoothstep插值；未受影响的像素跳过回转。新增低饱和蓝色隔离、活跃HSL的alpha和黄色锚点回归。
- 命名配方首次集成需在改变胶片时显式重新执行核心，而不是仅对旧核心结果做后处理；已增加renderPreviewIfNeeded，测试将实际filtered位图与目标胶片重新计算结果逐像素比较。
- 独立只读复核提示取消协程不能保证已进入IO的写入顺序。两种存储已改为单个串行写入协程加一个最新待存快照，保留AtomicFile事务；新请求不取消运行中的写入。
- 对话框名称使用remember(initial)；配方菜单可取消删除，删除不修改照片。
- 实机截图发现保存配方提示挡住底部导航；提示已上移，保留底部标签的可见与可点。
- 设备UI验收最初错误地把与滑块同名的文字标签当成滑块。工具现只匹配含RangeInfo的控件，操作后校验实际数值，不再把“请求过调整”当作已调整。
- 持久化测试不再用另一个AtomicFile实例反复openRead轮询正在写入的文件；该方法会执行事务恢复/清理。测试只轮询已提交的base文件，再验证重开读取，避免测试自身干扰写入。

未采纳“核心渲染期间禁用保存/改名/删除配方”的建议：这些操作读取不可变调色参数，不依赖已完成位图，禁用会造成多余等待。应用配方通过既有generation检查更新核心并显示进度；渲染期间保留上一帧是现有行为，最终帧由测试验证。

彩色/灰阶图、真实公开照片输出、图标安全圆和本机AdaptiveIconDrawable均有设备测试产物。最终19项JUnit、压缩Release语义/实际触摸流程、交付源码独立构建及哈希结果以交付验收记录为准。没有据此声称无障碍全面合规、所有GPU可用或完整VSCO等价。
